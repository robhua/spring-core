# Spring Core Example

Project mẫu để thực hành Spring Framework với Java 17. Project hiện giữ hai cách cấu hình Spring song song: annotation/Spring Boot và XML/JDBC.

## Công nghệ

- Java 17
- Spring Boot 4.1.1
- Maven
- Spring JDBC, HikariCP và PostgreSQL JDBC Driver
- JUnit 4 và Spring Test

## Cấu trúc

```text
src/main/java/core/
  annotation/   Ví dụ component scan, dependency injection và bean lifecycle
  xml/          Ví dụ cấu hình bean XML, service, DAO và JDBC
src/main/resources/
  application.properties  Cấu hình datasource cho Spring Boot
  beans*.xml              Cấu hình Spring XML
  jdbc.properties         Cấu hình datasource XML
src/test/                  Unit và Spring context tests
```

Project cung cấp giao diện MVC dùng Thymeleaf và REST API cùng thao tác trên một service/DAO nhân viên.

## Yêu cầu

- JDK 17
- Maven 3.6.3 trở lên
- PostgreSQL nếu chạy luồng XML/JDBC

Kiểm tra môi trường:

```bash
java -version
mvn -version
```

## Chạy ứng dụng

Khởi chạy ứng dụng web:

```bash
mvn spring-boot:run
```

Chuyển ngôn ngữ bằng nút `EN`/`VI` ở góc trên. Lựa chọn được lưu trong session; giao diện mặc định là tiếng Việt.

Mở [http://localhost:8080/employees](http://localhost:8080/employees) để quản lý hồ sơ. Dùng nút `EN`/`VI` ở header để đổi ngôn ngữ; lựa chọn được lưu theo session và mặc định là tiếng Việt. Nội dung tiếng Anh nằm trong `messages.properties`, tiếng Việt trong `messages_vi.properties`.

Danh sách hiển thị 10 hồ sơ mỗi trang, sắp theo tên A-Z rồi tuổi tăng dần; có thể chọn nhiều hồ sơ trên trang để xóa cùng lúc. Giao diện cũng hỗ trợ thêm, sửa, xóa đơn lẻ và kiểm tra dữ liệu đầu vào.

Chạy test và đóng gói:

```bash
mvn test
mvn package
java -jar target/SpringCoreExample-0.0.1-SNAPSHOT.jar
```

## PostgreSQL

Cả cấu hình Spring Boot trong `application.properties` và cấu hình XML trong `jdbc.properties` dùng chung các biến môi trường sau:

| Biến | Mặc định | Ý nghĩa |
| --- | --- | --- |
| `DB_URL` | `jdbc:postgresql://localhost:5432/mydb` | JDBC URL |
| `DB_USERNAME` | `postgres` | Tên đăng nhập PostgreSQL |
| `DB_PASSWORD` | bắt buộc | Mật khẩu PostgreSQL; không đặt trong source |

Ví dụ trên Linux/macOS:

```bash
export DB_URL=jdbc:postgresql://localhost:5432/mydb
export DB_USERNAME=postgres
export DB_PASSWORD='your-local-password'
```

Không commit mật khẩu thật vào repository. Database PostgreSQL `mydb` phải tồn tại và user phải có quyền tạo bảng; ứng dụng tự tạo bảng `employee` nếu bảng chưa có. H2 chỉ được dùng trong test (`application-test.properties`), không phải cấu hình chạy bình thường.

DAO truy vấn bảng `employee` với các cột `id`, `name`, `age`. Schema được khởi tạo an toàn bằng `CREATE TABLE IF NOT EXISTS` từ `src/main/resources/schema.sql`:

```sql
CREATE TABLE IF NOT EXISTS employee (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    age INTEGER NOT NULL
);
```

Chạy entry point XML để kiểm tra truy vấn JDBC:

```bash
mvn -Dexec.mainClass=core.xml.presentation.Main \
    -Dexec.classpathScope=runtime \
    org.codehaus.mojo:exec-maven-plugin:3.5.0:java
```

Luồng này tải `beans.xml`, tạo `JdbcTemplate`/Hikari datasource và gọi `EmployeeDAOImpl.findAllEmployees()`. Cần PostgreSQL đang chạy, credentials hợp lệ và bảng `employee` đã được tạo.

## REST API

REST API giữ cùng mô hình nhân viên và service với giao diện MVC:

| Method | Endpoint | Chức năng |
| --- | --- | --- |
| `GET` | `/api/employees` | Liệt kê nhân viên |
| `GET` | `/api/employees/{id}` | Xem một hồ sơ |
| `POST` | `/api/employees` | Tạo hồ sơ, trả `201 Created` và `Location` |
| `PUT` | `/api/employees/{id}` | Cập nhật hồ sơ |
| `DELETE` | `/api/employees/{id}` | Xóa hồ sơ, trả `204 No Content` |

Payload tạo/cập nhật là JSON, ví dụ `{"empName":"Nguyễn Minh An","age":32}`. Request sai dữ liệu trả `400`; ID không tồn tại trả `404`.

## Các luồng chính

- **Spring Boot/MVC**: `core.annotation.presentation.Main` khởi động web server và component scan; `core.xml.presentation.EmployeeController` phục vụ giao diện Thymeleaf.
- **REST API**: `core.xml.presentation.EmployeeRestController` cung cấp API cho frontend hoặc client khác.
- **XML/JDBC**: `core.xml.presentation.Main` nạp các file `beans*.xml` và đọc nhân viên qua `EmployeeService`/`EmployeeDAOImpl`.
